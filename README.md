# ⛳ 골프 스코어 대시보드

안남석(남돌군) 님의 골프 라운드 기록 대시보드입니다. 네이버 스포츠 MY골프 64라운드와 G Lounge에 기록된 남춘천CC 2라운드, 총 **66라운드 · 1,188홀**의 본인 스코어만 담았습니다.

- 라이브: https://namdoli.github.io/golf-score-dashboard/
- 데이터 기준: 2023-11-09 ~ 2026-11-13, 핸디캡 인덱스 17.7 (2026-11-08 기준)

## 기능

1. **핵심 요약 KPI & 연도 필터** — 전체/2026/2025/2024/2023 필터가 모든 섹션에 적용됩니다.
2. **골프장 지도(Leaflet)** — Esri Light Gray 타일의 연회색 미니멀 지도 위에 방문한 42개 골프장을 실제 좌표에 표시하고, 마커 크기·색으로 방문 횟수를 구분합니다. 확대하면 도로·지명이 은은하게 드러납니다. 마커에 마우스를 올리거나 클릭하면 지역·방문 횟수·평균/베스트 타수·최근 방문일·라운드 목록이 뜹니다.
3. **이동평균 & 성장 추이** — 라운드 타수, 5·10라운드 이동평균, 5라운드 베스트/워스트 밴드, 연도별 평균 비교.
4. **Par 3/4/5 공략 & 스코어 분포** — 파별 평균 타수와 오버파, 홀 결과(이글·버디·파·보기·더블·트리플+) 비율.
5. **전반(OUT) vs 후반(IN)** — 전·후반 평균, 라운드별 차이, 강한 구간 인사이트.
6. **목표 트래커** — 90타 미만(80대 진입), 80타 미만(70대 도전), 노 더블 파 달성 수와 최장 연속 기록.
7. **월별 히트맵 & 스코어카드** — 연도×월 라운드 빈도/평균, 검색·정렬 가능한 66라운드 표, 행을 누르면 18홀 스코어카드가 펼쳐집니다.
8. **스윙 영상** — 라운드에 연결된 스윙 영상을 표의 `🎬 스윙 영상` 배지·스코어카드 안의 플레이어·전체화면 모달로 바로 재생합니다. `🎬 스윙 영상만` 버튼으로 영상이 있는 라운드만 모아 볼 수 있습니다.

### 연결된 스윙 영상

| 라운드 | 코스 | 스코어 | 파일 | 길이 | 용량 |
|---|---|---|---|---|---|
| 2026-10-29 | 라비에벨CC 올드코스 | 90타 | `videos/lavieestbelle_old_20261029.mp4` (원본 IMG_7229) | 18.7초 | 2.0MB |
| 2026-10-30 | 라비에벨CC 듄스코스 | 95타 | `videos/lavieestbelle_dunes_20261030.mp4` (원본 IMG_2400) | 4.8초 | 1.0MB |

영상은 720×1280(H.264 High, CRF 26/25, `+faststart`, AAC 64k 모노)로 웹 최적화했고, 같은 이름의 `.jpg` 포스터 프레임을 씁니다. 연결 정보는 `data/videos.json`이 원본이며 `golf/make_data.py`가 `scores.json`의 해당 라운드에 `swingVideo` 필드로 붙입니다.

## 구성

```
index.html            화면
styles.css            스타일 (에메랄드/슬레이트, 모바일·PC 반응형)
app.js                데이터 집계 · 차트(Chart.js) · 지도(Leaflet) · 표/스코어카드
data/scores.json      정규화된 66라운드 (홀별 파·타수·파 대비, 연결된 스윙 영상 정보)
data/courses_geo.json 42개 골프장 좌표·주소
data/videos.json      라운드별 스윙 영상 연결 목록
videos/               웹 최적화 스윙 영상(mp4) + 포스터 이미지(jpg)
```

정적 파일만으로 동작하며 GitHub Pages(`main` 브랜치 루트)에서 제공됩니다. 차트와 지도는 CDN(Chart.js 4.4.1, Leaflet 1.9.4)을 사용하고, 지도 타일은 API 키가 필요 없는 Esri World Light Gray Base·Reference입니다(출처 표기 포함).

## 데이터 · 프라이버시

- 동반자 이름이나 동반자 스코어 등 다른 사람의 기록은 포함하지 않았습니다.
- 골프장 좌표는 카카오맵·구글맵 지오코딩 결과이며, 확인된 주소를 함께 표시합니다. 일부 골프장은 명칭이 바뀌었습니다(예: 참밸리CC → 코브스윙).
