# ⛳ 골프 스코어 대시보드

남돌군 님의 골프 라운드 기록 대시보드입니다. 네이버 스포츠 MY골프 65라운드 + G Lounge 남춘천CC 2라운드 + 직접 입력 1라운드 + 애플 캘린더 27라운드, 총 **95라운드** 가운데 스코어가 기록된 **67라운드 · 1,206홀**의 본인 스코어만 통계에 담았습니다.

- 라이브: https://namdoli.github.io/golf-score-dashboard/
- 데이터 기준: 2023-11-09 ~ 2026-11-27, 핸디캡 인덱스 17.7 (2026-11-08 기준)

## 기능

1. **핵심 요약 KPI & 연도 필터** — 전체/2026/2025/2024/2023 필터가 모든 섹션에 적용됩니다. 스크롤하면 제목(`남돌군의 골프 스코어`)과 평균·베스트·핸디캡, 연도 필터가 한 줄 고정 바로 상단에 붙어 현재 필터 기준 수치를 보여줍니다. `총 95라운드 · 스코어 67건`처럼 스코어 기록분과 미입력분을 구분해 표기합니다.
2. **골프장 지도(Leaflet)** — Esri Light Gray 타일의 연회색 미니멀 지도 위에 방문한 56개 골프장(국내 55 + 일본 홋카이도 루스쓰 1)을 실제 좌표에 표시하고, 마커 크기·색으로 방문 횟수를 구분합니다. 기본 뷰는 **국내 기준**으로 잡고, 지도 하단 `🇯🇵 홋카이도 루스쓰` 칩을 누르면 해당 마커로 줌인합니다(`🇰🇷 국내` 칩으로 복귀).
3. **실력 성장 추이** — 라운드별 스코어 흐름과 선형 성장 추세선, 연도별 평균 비교와 최근 5라운드 인사이트.
4. **Par 3/4/5 공략 & 스코어 분포** — 파별 평균 타수와 오버파, 홀 결과(이글·버디·파·보기·더블·트리플+) 비율.
5. **전반(OUT) vs 후반(IN)** — 전·후반 평균, 라운드별 차이, 강한 구간 인사이트.
6. **목표 트래커** — 90타 미만(80대 진입), 80타 미만(70대 도전), 노 더블 파 달성 수와 최장 연속 기록.
7. **월별 히트맵 & 라운드 기록** — 연도×월 라운드 횟수(색)와 평균 타수, 검색·정렬(날짜·골프장·타수·파 대비) 가능한 **카드형 라운드 목록**, 카드를 누르면 18홀 스코어카드 또는 스코어 미입력 안내가 바로 아래에 펼쳐지고, 야디지북이 있는 라운드(써닝포인트CC)는 `📓 야디지북` 배지와 함께 스코어카드 아래에 홀별 샷 기록이 이어집니다.
8. **스윙 영상** — 영상이 연결된 라운드는 카드의 `🎬 스윙 영상` 배지로 표시되고, 카드를 펼치면 스코어카드 안에서 바로 재생됩니다(전체화면 모달 지원). 별도의 영상 모아보기 섹션은 두지 않습니다.

## 구성

```
index.html            화면
styles.css            스타일 (에메랄드/슬레이트, 모바일·PC 반응형)
app.js                데이터 집계 · 차트(Chart.js) · 지도(Leaflet) · 카드형 라운드 목록/스코어카드
data/scores.json      정규화된 95라운드 (67라운드 홀별 스코어 + 28라운드 스코어 미입력)
data/courses_geo.json 57개 골프장 좌표·주소
data/videos.json      라운드별 스윙 영상 연결 목록
data/photos.json      라운드별 사진 연결 목록
data/yardage/         홀별 야디지북(홀 그림·그린맵·티별 거리·공략·라운드 중 샷 기록)
videos/               웹 최적화 스윙 영상(mp4) + 포스터 이미지(jpg)
photos/               웹 최적화 라운드 사진(jpg)
```

정적 파일만으로 동작하며 GitHub Pages(`main` 브랜치 루트)에서 제공됩니다. 차트와 지도는 CDN(Chart.js 4.4.1, Leaflet 1.9.4)을 사용하고, 지도 타일은 API 키가 필요 없는 Esri World Light Gray Base·Reference입니다(출처 표기 포함).

## 데이터 · 프라이버시

- 스코어가 없는 28라운드(애플 캘린더 27건 + 서원밸리CC 1건)는 라운드 횟수·지도 방문·월별 횟수에는 포함하고, 평균·베스트·이동평균·Par 분석·전후반·목표 트래커에서는 제외합니다.
- `2024-05-31`, `2025-10-23`은 캘린더에 장소가 없어 `장소 미기재 (캘린더)`로 목록·횟수에만 포함하고 지도에는 표시하지 않습니다.
- `월송리CC클럽하우스`는 `월송리CC`로, `루스쓰 리조트 Tower/Wood/Izumikawa/River Course`는 `루스쓰 리조트`(홋카이도) 1개 구장 4회로 합산했습니다.
- 동반자 이름이나 동반자 스코어 등 다른 사람의 기록은 포함하지 않았습니다(단체 사진 등 타인 식별 정보도 넣지 않음).
- 골프장 좌표는 카카오맵·구글맵 지오코딩 결과이며, 확인된 주소를 함께 표시합니다. 일부 골프장은 명칭이 바뀌었습니다(예: 참밸리CC → 코브스윙).
